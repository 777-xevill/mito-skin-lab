# Mito Skin Lab — front-end rebuild

Static HTML/CSS/JS rebuild of https://mitoskinlab.com/, built to the
**Website design**, **Departments**, **About Mito**, **Feedback 2/3/4** tabs.

## Run it

Just open `index.html` in a browser. Nothing to install.

To rebuild the inner pages after editing the shared header/footer in `build.js`:

```
node build.js
```

`index.html` is standalone and is **not** regenerated by the script — edit it directly.

## Files

```
index.html      Home
doctors.html    All 7 doctors, client's serial order
services.html   4 departments -> nested category tabs
shop.html       Left filter, hidden behind a button on mobile
product.html    Description / How to apply
about.html      About Us + Founder's Note
booking.html    Full booking form
build.js        Generates the 6 inner pages from one header/footer
css/mito.css    Palette, type, all components
js/data.js      Doctors, departments, services, products, reviews  <- edit content here
js/mito.js      Nav, tabs, filters, booking form, rendering
```

All site content lives in **`js/data.js`**. Change text there, not in the HTML.
